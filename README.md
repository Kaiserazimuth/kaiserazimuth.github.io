# Kaiser_Azimuth — Готовый сайт разработчика (GitHub Pages)

Полностью готовый архив со всеми файлами сайта (`index.html`, `README.md`, `assets/logo.png`, `assets/logo.jpg`, `assets/avatar.jpg`).

### Основные элементы сборки
- Миниатюрный античный навигационный прибор рядом с показателями `AZM / VEC / SYS` в верхней панели с синхронизацией стрелки по текущему азимуту.
- Крупный и лаконичный шрифт верхних кнопок справа и переключателя языка.
- Читаемый курсив для описаний, направлений работы, строки роли и списка стека.
- Кнопка **«Контакты»** (`#contact`) в блоке действий, ведущая к разделу контактов на странице.
- Единый переключатель языков без дублирования (`RU`, `EN`, `DE`, `中文`, `FR`).
- Описание и направления работы справа от фото, заполненный стек технологий, контакты (`kaiserazimuth@gmail.com`, Telegram `@Kaiser_Azimuth`, X `@Kaiser_Azimuth`), карточки проектов «Скоро будет» / «Soon», статус `available for work and for talk :)` и компоновка фото без пустых уголков.
