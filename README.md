# Kaiser_Azimuth — Готовый архив сайта для GitHub Pages (v56)

Содержимое архива готово к загрузке в корень репозитория `kaiserazimuth.github.io` для публикации по адресу `https://kaiserazimuth.github.io/`.

### Что обновлено в этой сборке
- **Уменьшены отступы в блоке описания:** снижены внешние и внутренние отступы (`padding`, `margin`, `gap`) и межстрочные интервалы внутри `.hero-card` и `.hero-desc` для более собранной и компактной компоновки.
- **Возвращены кнопки действий на своё место:** убран лишний закрывающий тег `</div>` перед `.hero-actions` и явно задано позиционирование/выравнивание кнопок («К проектам →», «Поддержать криптой», «Контакты») в нижней части блока описания.
- **Сохранены все предыдущие улучшения:** точный утверждённый текст описания и сфер приложения усилий, выделение «Kaiser Azimuth» шрифтом логотипа (`var(--gothic-display)`) с тенями и декоративным оформлением, курсив остального текста, выравнивание по ширине с отступами, одинаковая высота левого и правого блоков, уменьшенная на 20% фотография, автоопределение языка посетителя (`RU`, `EN`, `DE`, `中文`, `FR`), переключение языков от `RU_SOURCE` с сохранением в `localStorage`, миниатюрный античный навигационный прибор у `AZM / VEC / SYS`, контакты, заглушки «Скоро будет» / «Soon», раздел криптодонатов и все файлы в `assets/`.
