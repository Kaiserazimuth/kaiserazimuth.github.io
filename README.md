# Kaiser_Azimuth — Сайт разработчика (GitHub Pages)

## Структура проекта
```text
├── index.html          # Основная страница сайта
└── assets/
    ├── logo.jpg        # Логотип в шапке и фавиконка
    └── avatar.jpg      # Портрет разработчика в левой карточке
```

## Как загрузить на GitHub и включить сайт
1. Создайте на GitHub публичный репозиторий с именем `<ваш-логин>.github.io`.
2. Перейдите в репозиторий и нажмите **Add file → Upload files**.
3. Перетащите в окно браузера файл `index.html` и папку `assets` (с файлами `logo.jpg` и `avatar.jpg`), затем нажмите **Commit changes**.
4. Откройте **Settings → Pages**, выберите ветку `main` и папку `/ (root)`, нажмите **Save**.

## Как редактировать
* **Тексты, проекты, ссылки и стек:** откройте `index.html` прямо на GitHub (значок карандаша ✏️) или в любом редакторе кода (VS Code, Notepad++).
* **Картинки:** чтобы заменить логотип или фото, просто загрузите в папку `assets/` новые файлы с именами `logo.jpg` и `avatar.jpg` (или поменяйте пути в `index.html`).
