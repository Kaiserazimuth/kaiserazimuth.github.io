# Kaiser_Azimuth — Окончательный готовый сайт разработчика (GitHub Pages)

Полностью готовый архив со всеми файлами сайта (`index.html`, `README.md`, `assets/logo.png`, `assets/logo.jpg`, `assets/avatar.jpg`).

### Что реализовано в финальной версии
- **Исправлено переключение языков и автоопределение под посетителя:** убрана лишняя скобка внутри `applyLanguage`, при первом заходе язык автоматически подбирается под язык браузера посетителя (`ru`, `en`, `de`, `zh`, `fr`, с базовым русским по умолчанию), а при нажатии на кнопку выбора языка текст мгновенно переводится от русского исходного словаря (`RU_SOURCE`) и сохраняется в `localStorage`.
- **Миниатюрный античный навигационный прибор у `AZM / VEC / SYS`:** аккуратный круглый прибор в золотистой оправе со шкалой и стрелкой, синхронизирующейся с углом азимута.
- **Крупный лаконичный шрифт верхних кнопок справа:** чёткие шрифты навигации и переключателя языка.
- **Читаемый курсив:** изящный курсив с высокой читаемостью для описаний, направлений работы, строки роли и списка стека.
- **Кнопка «Контакты» (`#contact`):** ведёт к разделу контактов на странице.
- **Единый переключатель языков:** без дублирования (`RU`, `EN`, `DE`, `中文`, `FR`).
- **Полное наполнение и графика:** описание и направления работы справа от фото, стек технологий, контакты (`kaiserazimuth@gmail.com`, Telegram `@Kaiser_Azimuth`, X `@Kaiser_Azimuth`), карточки проектов «Скоро будет» / «Soon», статус `available for work and for talk :)` и все файлы графики в папке `assets/`.
