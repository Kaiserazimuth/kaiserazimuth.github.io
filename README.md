# Kaiser_Azimuth — Готовый архив сайта для GitHub Pages (v61)

Содержимое архива готово к загрузке в корень репозитория `kaiserazimuth.github.io` для публикации по адресу `https://kaiserazimuth.github.io/`.

### Что обновлено в этой сборке
- **Добавлен первый живой проект — `Solana Merchant Desk` (`SLOT // 01 · LIVE`):** в первую карточку раздела «Проекты» добавлено продуктово-маркетинговое описание некастодиального платёжного терминала и рабочего места мерчанта для приёма `SOL`, `USDC` и `SPL`-токенов, ключевые теги (`Solana Pay`, `Non-Custodial`, `USDC / SPL`, `Open Source`), золотистая акцентная подсветка карточки и прямая кнопка перехода в репозиторий `https://github.com/Kaiserazimuth/solana-merchant-desk`.
- **Полная мультиязычность проекта:** заголовок, описание и кнопка карточки переведены во всех 5 языковых словарях (`RU`, `EN`, `DE`, `中文`, `FR`).
- **Сохранены все предыдущие улучшения:** текст призыва к поддержке в разделе пожертвований, горизонтально выровненные 5 карточек кошельков (`Bitcoin`, `EVM & BNB`, `Solana`, `Tron`, `TON`) с QR-кодами, утверждённый текст описания и сфер приложения усилий, компактные отступы и кнопки действий, выделение «Kaiser Azimuth» шрифтом логотипа (`var(--gothic-display)`) с тенями, курсив основного текста, одинаковая высота левого и правого блоков, уменьшенная на 20% фотография, миниатюрный античный навигационный прибор у `AZM / VEC / SYS`, контакты и все файлы в `assets/`.
